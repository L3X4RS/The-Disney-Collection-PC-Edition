# The Disney Collection | PC Edition

**Launcher independente para Windows (x64) — QuackShot e Castle of Illusion.**

Projeto não oficial desenvolvido por **L3X4RS**. O código-fonte do launcher não é distribuído neste repositório. Os arquivos compilados, quando publicados, estarão na seção **Releases**.

## Português (Brasil)

O The Disney Collection | PC Edition reúne duas aventuras clássicas do Mega Drive numa interface para Windows, com português brasileiro e inglês, suporte a controles, proporções 16:9/4:3, filtros CRT, opções de HDR e gerenciamento separado de cartuchos e salvamentos.

**Instalação:** baixe o pacote para Windows em [Releases](../../releases), extraia-o e execute `DisneyCollection.exe`. Na aba **Biblioteca**, importe os arquivos dos seus cartuchos compatíveis.

**Cartuchos suportados:** QuackShot (CRC32 `A41C456B`) e Castle of Illusion (CRC32 `C9AFBB88`).

**Importante:** não fornecemos ROMs, jogos, músicas ou imagens dos personagens. Os usuários devem utilizar seus próprios arquivos compatíveis, obtidos de forma autorizada.

## English

The Disney Collection | PC Edition is an independent Windows x64 launcher for two classic Mega Drive adventures, featuring English and Brazilian Portuguese, controller support, 16:9 / 4:3 display options, classic CRT filtering, HDR options, cartridge import, and individual game saves.

**Installation:** download the Windows package from [Releases](../../releases), extract it and run `DisneyCollection.exe`. Use the **Library** page to import your own compatible cartridge files.

**Verified cartridges:** QuackShot (CRC32 `A41C456B`) and Castle of Illusion (CRC32 `C9AFBB88`).

**Important:** no game ROMs, copyrighted character artwork, game music or proprietary game content are distributed. Users must supply their own authorized compatible game files.
